# Voodi

Лендинг финансовой prop-trading платформы. Сайт для трейдеров — с котировками рынков, описанием платформы, аналитикой и FAQ. Чистый HTML/CSS/JS, без фреймворков.

## О проекте

Voodi — лендинг проп-трейдинговой компании, где трейдеры торгуют капиталом фирмы в симулированной среде. Сайт представляет платформу, её возможности и рынки.

## Стек

- **HTML / CSS / Vanilla JS** — без фреймворков и сборщиков
- **Intersection Observer API** — анимации появления секций при скролле
- **CSS анимации** — параллакс-фон, прелоадер, счётчики

## Секции

| Секция | Описание |
|---|---|
| Hero | Заглавный экран с параллакс GIF-фоном |
| Partners | Партнёры: Freedom, Halyk, CME, Kaspi, KASE, Google |
| Features | Возможности платформы: Market Replay, Charts, Connections |

| Markets | Котировки Forex / ETF / Futures по вкладкам |
| Insights | Аналитические статьи и новости рынка |
| FAQ | Аккордеон с вопросами о проп-трейдинге |
| Contact | Discord, поддержка, подписка на рассылку |

## Запуск

Проект не требует установки — просто открой файл в браузере.

### Вариант 1 — открыть напрямую

Дважды кликни на `index.html`.

### Вариант 2 — локальный сервер (рекомендуется)

Через Python:

```bash
python -m http.server 8080
```

Или через расширение **Live Server** в VS Code — кнопка **Go Live** в нижней панели.

Затем открыть **http://localhost:8080**

## Анимации

- **Прелоадер** — спиннер при загрузке страницы (2 сек)
- **Параллакс** — фон hero-секции масштабируется при скролле
- **Reveal on scroll** — секции плавно появляются при прокрутке
- **Счётчики** — числа анимированно считают до цели при попадании в экран
- **Шейк** — поле email трясётся при вводе невалидного адреса
- **Аккордеон** — плавное раскрытие FAQ
- **Модалка** — подтверждение подписки на рассылку
